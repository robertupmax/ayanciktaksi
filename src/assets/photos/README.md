# Fotoğraflar

Fotoğrafları bu klasöre atın. **Dosya adı önemlidir** — aşağıdaki adlarla
birebir aynı olmalı. Uzantı `.jpg`, `.jpeg`, `.png` veya `.webp` olabilir.

Dosya yoksa o bölüm sitede hiç görünmez; site bozulmaz. İstediğinizi
ekleyip istediğinizi boş bırakabilirsiniz.

## Taksiye ait (öncelikli)

| Dosya adı | Nerede görünür |
| --- | --- |
| `taksi-hero` | Anasayfanın en üstü — en iyi fotoğrafınız buraya |
| `soför-huseyin-cokluk` | Hakkımızda sayfası |
| `taksi-ic` | Hakkımızda sayfası |
| `taksi-bagaj` | Hakkımızda sayfası — bagaj hacmini gösteren kare |

## İpuçları

- **Yatay (manzara) çekin.** Bölümler 16/9 oranında gösteriliyor.
- **En az 1600 piksel genişlik** olsun; Astro küçültmeyi kendi yapar,
  büyütemez.
- Dosya boyutunu küçültmeye uğraşmayın, sıkıştırma otomatik.
- **Kendi çektiğiniz fotoğrafları kullanın.** İnternetten alınan
  fotoğraflar telif sorunu yaratır; ayrıca gerçek fotoğraflar Google
  İşletme Profili ile birlikte yerel aramada daha iyi çalışır.
- Taksinin plakası görünen bir kare işe yarar — arayanlar aracı tanır.
